Purpose

This report exists because an earlier version of this analysis silently used ground-truth masks in a directory (held_out_results/) that was supposed to demonstrate genuine held-out model performance — the model's own prediction sat unused the entire time. That error was caught and fixed. This report re-derives, from first principles and with the underlying checksums/timestamps shown explicitly, that:

  1. Each pair of slides below was physically absent from the training data directory for the entire duration of the training run used to generate its prediction — verified by name, not just count, against the trainer's own logged train/validation slide lists.
  2. The predicted masks quantified below come from that exact checkpoint, applied to the untouched raw slide images, upsampled correctly from the model's padded prediction canvas back to native resolution before any distance/intensity math was computed.
  3. The ground-truth baseline quantification used the literal annotation files from the source dataset, unmodified.
  4. Both ground-truth and predicted quantification used the identical analysis code.
